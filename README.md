<h1 align="center">BarySim</h1>
<p align="center">Солнце, планеты и общий центр масс системы</p>

---

Барицентр Солнечной системы лежит в среднем в 830 тыс. км от центра Солнца — за
фотосферой, радиус которой 696 тыс. км. Проект показывает это в движении:
три ракурса с общим курсором времени, окно 20 000 лет, эфемериды JPL DE441.

- **Три ракурса** — лог-карта орбит, смещение Солнца относительно барицентра,
  график расстояния с двумя шкалами.
- **Вклад планет** — Юпитер смещает центр на 742 тыс. км, Сатурн — на 407 тыс.
- **Регулируемый темп** — от 0,5 до 12 лет в секунду, быстрые планеты
  смазываются в кольца.
- **Ручная дата** — ввод с клавиатуры (`1804` или `19.04.1804`) и ползунок
  на графике, который тянется мышью.
- **Светлая и тёмная темы** — переключатель в панели, по умолчанию как в системе.
- **Адаптив** — сцены квадратные и занимают всю доступную высоту: на 1920×1080 это
  713 px, на 1440×900 — 535, на 1366×768 — 449. Прокрутки нет ни на одном
  разрешении, кроме телефона.
- **Три раскладки** — шире 1200 px две сцены и колонка управления справа; в портрете
  761–1200 шапка и управление становятся левой колонкой 220 px, сцены — правой;
  уже 760 px всё в одну колонку.
- **Сводка по окну** — максимум, минимум и доля времени вне фотосферы для выбранного
  диапазона.
- **Теория в окне** — центр масс, формула, ключевые числа; открывается ссылкой в шапке.
- **Произвольное окно** — пресеты и Shift + протяжка по графику.
- **Две версии** — аналитическая страница с тремя ракурсами и кинематографическая
  сцена с камерой и свечением.
- **Без зависимостей** — один HTML-файл, canvas 2D, данные внутри.

## Быстрый старт

```bash
git clone https://github.com/AlexanderKuzikov/BarySim.git
cd BarySim
start barycenter.html   # аналитическая версия, три ракурса
start cinematic.html    # кинематографическая версия
```

Пересборка из эфемерид:

```bash
python fetch.py        # скачать horizons_bary.txt с JPL Horizons
python build_data.py   # разобрать в hz.json
python build.py           # вставить данные в barycenter.html
python build_cinematic.py # собрать cinematic.html
node smoke.mjs            # 16 проверок аналитической версии
node smoke_cinematic.mjs  # 21 проверка кино-версии
```
