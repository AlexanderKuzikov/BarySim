# BarySim — инструкции для AI-агентов

## Команды

- сборка данных: `python fetch.py && python build_data.py`
- сборка страницы: `python build.py`
- сборка кино-версии: `python build_cinematic.py`
- проверка: `node smoke.mjs`, `node smoke_cinematic.mjs`
- статистика вкладов: `python analyze.py`
- сверка модели с Horizons: `python compare.py` (нужен `horizons.txt`)

## Конвенции

- Python вызывается как `python`, не `python3`.
- Страница — один файл без зависимостей и без сборщика. Никаких npm-пакетов,
  CDN-скриптов и внешних шрифтов: `barycenter.html` должен открываться офлайн.
- Данные встраиваются в HTML на этапе сборки, а не подгружаются через fetch —
  иначе страница не работает по `file://`.
- Числа в интерфейсе — с разделителем разрядов, расстояния в километрах.
- Тексты интерфейса — по-русски, заголовки обычным регистром.

## Структура

- `bary.py` — кеплеровская модель планет (элементы Standish) и функция
  смещения барицентра; используется `analyze.py` и `compare.py`.
- `fetch.py` — выгрузка векторов барицентра из JPL Horizons в `h1500.txt`.
- `build_data.py` — разбор `h1500.txt` в `hz.json` (плоский массив x,y,z).
- `template.html` — шаблон страницы с плейсхолдером `{{DATA}}`.
- `build.py` — подстановка `hz.json` в шаблон, результат `barycenter.html`.
- `template_cinematic.html` — шаблон кинематографической сцены, тот же `{{DATA}}`.
- `build_cinematic.py` — сборка `cinematic.html`.
- `smoke.mjs` — headless-стенд аналитической версии, 16 проверок.
- `smoke_cinematic.mjs` — стенд кино-версии, 21 проверка (включая проекцию).
- `analyze.py` — таблица вкладов планет и статистика 1800–2200.
- `compare.py` — сверка кеплеровской модели с эталоном Horizons.

## Не трогать

- `h1500.txt` — 7 МБ сырого дампа Horizons, в git не хранится, восстанавливается
  через `fetch.py`.
- `hz.json` — производный файл, но лежит в репозитории намеренно: без него
  `build.py` не работает офлайн.
